# Product Requirements Document (PRD)

## Target Audience
Civil engineering students, structural designers, and project managers looking for rapid visual concept modeling and code-aligned preliminary specs.

## Key Features
1. Parameter Selector: Dropdowns for structural types (Concrete Girder Bridge, High-Rise Residential Tower, Post-Tensioned Flat Slab).
2. Code Selector: Toggle between ACI 318M (Buildings) and AASHTO LRFD (Bridges).
3. Prompt Engine: Instant formatting of text prompts tailored for 3D generative engines.
4. Specs Engine: Instant generation of structural design limits, load considerations, and material guidelines.
