# Project Scope: AI Civil Prompt & Specs Generator

## Objective
Provide an intuitive web application that translates civil engineering structural parameters into optimized 3D generative prompts and compliant specification summaries.

## In-Scope
- Web-based interactive interface for specifying structural parameters.
- Text-to-3D prompt generator tuned for generative AI engineering models.
- Automated structural specs summary builder adhering to international codes.

## Out-of-Scope
- Heavy finite element calculations (FEA).
- Direct API rendering of 3D meshes inside the browser.
